# Fish的雅思题库 · 雅思练习

一个可离线使用的雅思学习题库，包含听力、阅读、写作和口语练习。题目、图片、录音与离线英汉词典均随完整离线包提供，无需登录或连接云端。

## 使用方法

1. 在 Releases 下载完整离线包，解压全部文件。
2. 双击 index.html，或在 Windows 双击“打开题库.cmd”。建议使用 Edge、Chrome 或 Firefox。
3. 选择科目开始练习。阅读原文和题目上下同屏，各自独立滚动。

## 题库与功能

- 310 组练习：听力 21 组、阅读 178 篇、写作 45 篇、口语 66 组。
- 听力包含 10 套完整试卷、400 道题、40 段录音，以及专项练习与公开版权录音。
- 支持答案核对、解析、作文和口语笔记、生词本、划词、高亮、数据记录与学习统计。
- 内置离线英汉词典；来源网站、在线查词与翻译链接仅是可选外部参考，需要网络。

## 记录保存

首次使用时生词本、答题记录、统计、作文和口语笔记均为空。后续记录只保存在当前设备和浏览器中，不上传、不跨设备同步。使用独立的离线存储空间，不读取原网站的个人记录。清除浏览器数据、更换浏览器或移动文件位置可能导致记录无法读取，请通过“数据记录”导出备份。

## 下载说明

仓库保存离线页面和题库文件。完整录音与图片随 Releases 的 ZIP 提供；仅下载仓库源码不包含这些媒体。解压时保持 index.html、data 和 assets 的相对位置。
